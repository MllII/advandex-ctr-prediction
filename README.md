\# Advandex CTR Prediction Pipeline: Calibrated Model for Real-Time Bidding



Предсказание вероятности клика (CTR) для AdTech-платформы Advandex.



\---



\## Описание проекта



В рамках проекта разработана модель бинарной классификации для предсказания вероятности клика (Click-Through Rate, CTR) на рекламное объявление. Модель предназначена для использования в системах Real-Time Bidding (RTB) для расчёта ожидаемого дохода по формуле:



> \*\*Ожидаемый доход = Ставка × Predicted CTR\*\*



\### Ключевые требования:

\- \*\*Интерпретируемость\*\* — понимание факторов, влияющих на клик

\- \*\*Калибровка\*\* — точные вероятности для расчёта ожидаемого дохода

\- \*\*Воспроизводимость\*\* — фиксация `random\_state=42`

\- \*\*Готовность к продакшену\*\* — пайплайн для промышленного использования



\---



\## Данные



\*\*Источник:\*\* датасет `ds\_s16\_ad\_click\_dataset`



\*\*Размер:\*\* 50 000 строк, 34 столбца



\*\*Целевая переменная:\*\* `click` (1 — клик, 0 — нет клика)



\*\*Особенности данных:\*\*

\- Анонимизированные категориальные и числовые признаки

\- Данные о пользователях, устройствах, рекламных площадках и аукционах

\- Машинно-сгенерированные признаки (ML features)



\---



\## Модель



\### Этапы построения модели:



1\. \*\*EDA\*\* — анализ данных, корреляции, выбросы

2\. \*\*Предобработка\*\* — кодирование категориальных признаков, масштабирование

3\. \*\*Отбор признаков\*\* — фильтрационные методы (VarianceThreshold) + обёртка (RFE)

4\. \*\*Обучение\*\* — логистическая регрессия с подбором гиперпараметров (GridSearchCV)

5\. \*\*Калибровка\*\* — Isotonic Regression для улучшения качества вероятностей



\### Лучшая модель:



| Параметр | Значение |

|----------|----------|

| \*\*Модель\*\* | LogisticRegression |

| \*\*Гиперпараметры\*\* | `C=1.0, penalty=l2, solver=liblinear` |

| \*\*Калибровка\*\* | Isotonic Regression |

| \*\*Отбор признаков\*\* | RFE (20 признаков) |
